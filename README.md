# FASHION AMA: сайт с сервером

Розовый онлайн-шкаф с ИИ-стилистом. Посетителям **не нужен Claude**: нейросеть работает через сервер, который тратит деньги с вашего API-ключа.

## Что в папке

| Файл | Что делает |
|---|---|
| `index.html` | Сам сайт: то, что видят посетители |
| `api/stylist.js` | Сервер: собирает образ и список «что докупить» |
| `api/describe.js` | Сервер: смотрит на фото вещи и подсказывает, что это |
| `api/_claude.js` | Общий код: отправляет запросы в Claude и защищает от спама |
| `package.json` | Описание проекта для хостинга |

Ключ API хранится **только на сервере** (в настройках Vercel), в браузер посетителя он никогда не попадает.

## Шаг 1. Ключ Claude API (делает взрослый)

Подписка Claude и Claude API — это разные вещи: для сервера нужен отдельный ключ с оплатой за использование.

1. Взрослый (API доступен только с 18 лет и только в [поддерживаемых странах](https://www.anthropic.com/supported-countries)) заходит на **console.anthropic.com** и регистрируется.
2. Пополняет баланс (Billing). Для школьного проекта хватит минимальной суммы.
3. **Обязательно** ставит лимит расходов в месяц (Limits / Spend limit), чтобы случайно не потратить лишнее.
4. Создаёт ключ: **API Keys → Create Key**. Ключ начинается с `sk-ant-…`. Никому его не показывайте и не вставляйте в `index.html`.

## Шаг 2. Загрузить файлы на GitHub

1. Зарегистрируйтесь на **github.com**.
2. Нажмите **New repository** → назовите `fashion-ama` → **Create repository**.
3. Нажмите **uploading an existing file** и перетащите все файлы из этой папки, **вместе с папкой `api`**.
4. Нажмите **Commit changes**.

## Шаг 3. Запустить сайт на Vercel (бесплатно)

1. Зайдите на **vercel.com** → **Sign Up** → **Continue with GitHub**.
2. **Add New → Project** → выберите репозиторий `fashion-ama` → **Import**.
3. Откройте **Environment Variables** и добавьте:
   - Name: `ANTHROPIC_API_KEY`
   - Value: ваш ключ `sk-ant-…`
4. Нажмите **Deploy**. Через минуту появится ссылка вида `fashion-ama.vercel.app`. Её можно отправлять всем!

Если поменяли ключ или настройки: **Deployments → … → Redeploy**.

## Необязательные настройки

Их тоже можно добавить в Environment Variables:

| Имя | Что значит | По умолчанию |
|---|---|---|
| `STYLIST_MODEL` | Модель для стилиста | `claude-sonnet-5-5` |
| `DESCRIBE_MODEL` | Модель для распознавания фото | `claude-haiku-5-5` (самая дешёвая) |
| `REQUESTS_PER_MINUTE` | Сколько запросов в минуту можно с одного устройства | `8` |

Чтобы тратить меньше, поставьте `STYLIST_MODEL` = `claude-haiku-5-5`.

## Если что-то не работает

- **«На сервере не настроен ключ нейросети»** — не добавили `ANTHROPIC_API_KEY` или не сделали Redeploy.
- **Образ собирается «по правилам»** — сервер не ответил. Посмотрите ошибки в Vercel: **Project → Logs**.
- **«Нейросеть устала»** — слишком много запросов подряд, или закончился баланс / сработал лимит в консоли Anthropic.

Шкаф, образы и лукбук хранятся в браузере каждого посетителя, на сервер фото одежды не сохраняются. Фото отправляется в нейросеть только при нажатии кнопки «ИИ, что это за вещь?».
