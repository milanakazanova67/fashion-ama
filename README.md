# FASHION AMA

Розовый онлайн-шкаф с ИИ-стилистом. Школьный проект.

Создательницы: Казанова Милана, Гребенюк Ариана, Масленникова Алиса.

## Как это устроено

- **Сайт** — `index.html`, размещён на GitHub Pages.
- **Сервер** — функция в Yandex Cloud Functions (`fashion-ama`). Она хранит ключ GigaChat и отправляет запросы нейросети. Ключ никогда не попадает в браузер посетителя.
- **Нейросеть** — GigaChat (Сбер), модель GigaChat-2-Pro, бесплатный пакет токенов для физлиц.

Шкаф, образы и лукбук хранятся в браузере каждого посетителя. Фото одежды отправляется в нейросеть только при нажатии «ИИ, что это за вещь?».

## Если что-то сломалось

- Образ собирается «по правилам» — сервер не ответил. Логи: Yandex Cloud → Cloud Functions → fashion-ama → Логи.
- Закончились токены — проверьте баланс на developers.sber.ru.
- Поменяли ключ GigaChat — Cloud Functions → fashion-ama → Редактор → переменная GIGACHAT_AUTH_KEY → Сохранить.
